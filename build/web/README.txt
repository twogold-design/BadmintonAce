谁是羽毛球高手 / BADMINTON ACE

Godot 4.7.2 · WebGL 2 · 键盘操作 · 3D 骨骼角色与程序动作、合成音效

提交文件：BadmintonAce-Web.zip，解压后根目录为 index.html。
上传全部文件到比赛平台，入口选 index.html。公网托管使用 HTTPS，本机可使用 localhost HTTP；也支持在新版 Chrome / Edge 中直接双击本地 index.html。
本地打开时请先完整解压并保留 local-data.js、local-loader.js 等配套文件。登录页可选择“单机游玩”，无需账号和服务器即可挑战或练习；登录后可参与积分及在线对战，首次登录自动创建账号。
单线程 Web 导出，不需要跨源隔离头。需支持 WebGL 2 的桌面浏览器。

模式：
1. 单人挑战：可选择石宇奇、安塞龙、周天成、昆拉武特、安洗莹、陈雨菲、王祉怡、山口茜八位 AI 对手。每位对手仅首次获胜 +5 积分，之后可无限重复挑战。可选择入门 / 进阶 / 高手三档 AI。
2. 在线 1v1：两个人使用各自电脑，通过空闲房间列表加入。
当前默认局域网联机：主机运行 BadmintonAce-Server.exe，其他玩家完整解压网页包后打开本地 index.html，无需手动填地址（预设主机 10.11.179.27:8766；IP 变化时由组织者更新 config.js）。
玩家一：在线对战 → 右侧创建房间，密码可留空。玩家二：在线对战 → 左侧选中空闲房间 → 加入；只有密码房才要求输入密码。
账号采用账号名＋密码登录，首次登录自动创建，换电脑可继续使用积分。首页顶部点击“积分排行榜”按钮展开榜单，1v1 获胜 +10 分，失败不加分；提前退出判负，对手获胜。双方通过 WebRTC 直连传输实时对战数据，服务器仅处理账号、房间、协商和积分结算。服务器不转发游戏状态，无法直连时不开始比赛。
3. 自由练习：AI 陪练，无输赢压力。

角色：主菜单“角色”可选男女并预览正背面。选择自动保存并在开局时同步给对手；男女操作能力一致。

控制：
WASD 移动；J 放网/吊球，K 高点杀球/低位平抽，L 高远/低位挑球。只使用三个击球键，I 不再击球。J 发短球，L 发高远球。
按住蓄力，松开击球。挥拍同时按方向可改变落点。靠近球并短蓄力触发甜区。
吊球：按住 J，用 A/D 选左右，W/S 选屏幕方向的深浅，停步后仍保留瞄准；场内显示落点预览。
不按方向时，吊球会寻找对手空位，并变化落点与深度。
杀球及其他回球也会自动变化左右与深浅、减少连续重复落点。K + A/D 指定杀球左右，W/S 调整深浅；手动瞄准优先。
Space 跳跃（配合 K 跳杀），左 Shift 蹬步救球，H 预计轨迹/落点/高度参考线，C 底线/俯视镜头，Esc 暂停。
默认拉近的低位底线透视，高球时适度放宽镜头；绿色地胶与深色场外区域、广告围挡、裁判席；放大球场、精简两侧信息栏，保留球尾迹、连续预测弧线和落点圈，不显示落地时间。松键后 0.36 秒击球缓冲，近距离停步时小幅辅助接球，手动移动优先；不同球路采用不同挥拍动作。
联机双方均使用同一套按键，各自以自己的底线为主视角，自己背对镜头；W 向网、S 后退、A/D 为自己画面左右。P2 的球、速度与动作按同一时间缓冲显示，减少轨迹抖动。
动作包括小步调整、侧向并步、后退步、网前跨步、侧身准备、髋肩依次转动、重心转移、跳起换脚和落地回正。

规则：每球得分，单打内边线，下网/出界失分。赢球方发球，随得分奇偶交换发球区。
所有比赛固定为 11 分制，需领先 2 分，15 分封顶，不提供分制切换。

联网说明：静态比赛平台不能运行房间服务。局域网对战需由主机运行单独提供的 EXE 服务；服务端不计入网页参赛包。
服务器不限制玩家来源网段，能访问主机 TCP 8766 端口即可登录和使用房间、排行榜；开赛还要求两台玩家电脑允许 WebRTC 直连通信。目前没有部署公网入口。主机首次或从旧版本升级后需以管理员身份运行“允许局域网联机.cmd”，允许跨子网访问服务器。
单机挑战和自由练习无需服务器，不计入账号积分。账号积分和在线对战需要服务器持续运行。HTTPS 比赛平台网页需另部署可访问的 WSS 服务并修改 config.js；当前预设内网地址不可供异地玩家使用。当前 WebRTC 仅配置局域网直连，不包含 TURN 中转。
主机步骤见服务端包 docs/局域网使用说明.md；未来公网部署见 docs/部署与邀请.md。
