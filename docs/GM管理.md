# GM 管理

在服务器电脑上启动新版 `BadmintonAce-Server.exe`，再双击根目录的 **GM管理.cmd**。默认入口为 http://127.0.0.1:8766/gm 。其他玩家电脑无法访问 GM。

房间、账号、积分数据库和 GM 管理均由同一个 `BadmintonAce-Server.exe` 提供。后续更新使用这个固定文件名，沿用同目录的 `data` 数据；无需单独的 GM 服务器程序。更新正在运行的程序前，先结束当前对局并关闭服务。

支持搜索、分页查看账号；对单个或全部账号清除积分、删除账号。每次操作必须在弹窗中输入目标账号名；全局操作需输入“清除全部积分”或“删除全部账号”。

- 清除积分：积分归零，清空挑战首胜领取记录，可以重新挑战领奖；胜场、场次保留。
- 删除账号：删除账号、积分、登录凭证、挑战记录以及涉及该账号的对局记录；其他玩家的积分与胜负统计保留。删除后再次登录同名账号会自动创建新账号。
- 受影响账号会退出登录，进行中的挑战失效；涉及的在线房间取消，不按逃跑判负，也不给对方加分。

每次执行前自动保存完整数据库到 `data/gm-backups/`。页面下方可以查看最近管理记录及备份文件名。需要恢复时，先关闭服务器，保留当前数据库及其 `-wal`、`-shm` 文件，再把选定备份复制为 `data/rankings.sqlite`，移开旧的 WAL/SHM 文件后重启。恢复会还原整个服务器数据到备份时点。

管理密钥保存在 `data/gm-key.txt`，首次启动自动生成。启动器通过浏览器地址的片段传递密钥，页面读入后立即从地址栏移除；不会把密钥发进普通网页请求或写入游戏文件。不要把数据目录、密钥或备份发给玩家。只允许来自本机、使用 localhost/127.0.0.1 的访问，并检查来源与管理凭证。

使用自定义 `DATA_DIR`、`PORT` 时，服务器和 GM 启动器使用相同环境变量。GM 页面由服务器直接提供；本次也已更新网页游戏，使管理操作后显示对应提示并清除本地登录状态。

开发验证：先运行 `tools/environment.ps1`，再用 Node 24 执行 `server/test-gm.js`。测试会启动独立端口 18769，数据只写入 `.runtime/gm-test-*`；设 `ACE_GM_BROWSER=1` 可同时验证管理页面与游戏退出登录，设 `ACE_GM_EXE` 可指定待测的服务器程序。不会连接或清理正式玩家数据库。
