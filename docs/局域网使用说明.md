# 局域网双人对战

当前版本采用房主计算比赛、WebRTC 数据通道直连。服务器通过 WebSocket 处理账号、积分、房间、直连协商和结果；实时对战数据不经过服务器。没有 TURN 转发或服务器转发回退。只能连接同一可互通局域网；Wi-Fi 的访客隔离、校园网隔离可能阻止设备互访。

单机玩家可直接在登录页点击“单机游玩”，无需启动服务器；挑战八位 AI 对手和自由练习均可使用，单机成绩不计入账号积分。在线对战和积分使用下方的服务器步骤。

## 主机准备（只做一次）

1. 将完整服务端包解压到可写目录。主机双击 `BadmintonAce-Server.exe` 并保留窗口，或者双击 `开始游戏.cmd` 在后台启动服务并打开主机游戏。无需安装 Node.js 或 Godot。
2. 右键 `允许局域网联机.cmd`，选择“以管理员身份运行”。它只放行这个 EXE 的 TCP 8766 端口，来源限本地子网；不会关闭防火墙。
3. 服务窗口会列出 `ws://主机内网IP:8766/ws`。如果主机有多个网卡，选择与玩家相连的那个网络地址。
4. 将 `dist/BadmintonAce-Web.zip` 发给其他玩家。所有玩家完整解压，保留全部配套文件；不要只发送一个 HTML。

## 玩家一：创建房间

1. 打开新版 `index.html`，输入“账号＋密码”登录（首次登录自动创建账号），进入“在线对战”。房间使用已登录的账号名。
2. 密码留空就是公开房；填写密码就是密码房。
3. 点击右侧“创建房间”，自己的房间立即出现在左侧空闲列表。保持游戏页面打开，等待玩家二进入；点击“关闭我的房间”可取消等待。

## 玩家二：加入房间

1. 在自己的电脑上完整解压游戏包，双击本地 `index.html`。
2. 进入“在线对战”，左侧直接显示空闲房间列表，房间创建、满员或关闭时实时更新。
3. 选中房间 → “加入选中房间”。公开房直接加入；密码房会显示独立密码页，输入正确密码后加入。
4. 双方建立直连后才进入球场开赛；P1 用 J 或 L 发球。直连失败会返回房间列表，不记输赢。

普通玩家无需填写地址或房间码。本次下载版已预设主机 `ws://10.11.179.27:8766/ws`。主机 IP 变化时，由组织者统一修改网页包的 `config.js`。开发配置源为 `tools/web-config.js`。建议路由器为主机保留固定 IP。角色在主菜单选择，在线对战页不提供角色切换或连接设置。

`127.0.0.1` 只代表当前电脑；它不能用来连接另一台电脑。`ws://` 是服务连接地址，不是浏览器网页地址。

普通内网 `http://主机IP` 不满足 Godot 网页的安全上下文要求。其他玩家请使用本地完整游戏包，不要直接打开内网 HTTP 游戏页。

## 加入失败时

- 在玩家二的浏览器访问 `http://主机内网IP:8766/health`。这只是检查页；正常应出现 `ok: true`、`lanOnly: true`。打不开说明服务、防火墙或网络隔离有问题。
- 检查两位玩家是否都用新版文件、同一个地址和 8766 端口。旧版本的 8765 房间不能混用。
- 密码错误、房间已满、房间已结束会在游戏内提示。服务重启后旧房间码失效，需要重新创建。
- 同机测试请把两个浏览器窗口并排显示。切换标签页、最小化或遮挡窗口可能让浏览器暂停后台画面；恢复显示时客户端会跳过积压状态，跟上最新比赛，不再慢慢回放旧球路。两台电脑测试更适合检查实际联机手感。
- 浏览器询问本地网络访问权限时，允许此游戏访问局域网。
- 同 Wi-Fi 不一定能互访：访客 Wi-Fi、AP 隔离、校园/公司策略可能隔离设备。

## 排行榜与保存

首页顶部点击“积分排行榜”展开榜单，点击“收起”或按 Esc 关闭，首页演示持续播放。八位 AI 对手均可无限挑战，但同一账号对同一位对手仅首次获胜 +5 分；1v1 每场获胜 +10 分，失败 +0 分，自由练习不计分。正常对战双方提交相同结果后结算；比赛结束前先退出或被服务器确认断线的一方判负，对手获胜 +10 分，房主同样适用。暂停菜单“退出比赛（判负）”、关闭游戏页都适用；无响应连接需等待心跳确认。同一场和同一挑战首胜奖励不会重复计分。

服务器不接收对战过程中的比分；退出判负时各自页面仅展示本地最后看到的比分，服务器单独保存胜负。如果只有直连路径失效、双方仍连接服务器，则无法判断责任方，本局取消、不计分。

未开赛的等待房间关闭不计输赢。服务器已收到决胜比分后再退出，保留比赛结果，不改判；服务器自身关闭或重启不作为玩家退出判负。

换电脑或浏览器后，使用同一账号和密码登录同一服务器即可继续使用积分。账号名不区分英文大小写，密码至少 3 位。本地会话凭证有效期为 30 天；切换账号会注销当前凭证。不允许同一账号自我对战，也不允许同一账号在多个页面同时进行比赛。

主机的 `data/rankings.sqlite` 保存身份和战绩；它不通过网页对外提供。备份时先正常关闭服务，再复制整个 `data` 目录。关闭服务会断开所有对局，重启后排行榜保留，房间不保留。

这是房主权威的休闲战绩榜：双方确认和重复结算检查能减少错误，不代表竞技级防作弊。

## 访问限制

默认 `LAN_ONLY=1`，HTTP 和 WebSocket 均拒绝公网源地址及带转发头的代理请求。主机防火墙配合 `LocalSubnet` 规则限定本地子网。不要设置公网端口映射、穿透或反向代理；某些隐藏来源的代理无法仅靠应用判断真实来源。

服务器默认端口 8766；程序和排行榜保存在 EXE 所在目录。移动程序目录后，需要重新运行防火墙脚本更新程序路径。
