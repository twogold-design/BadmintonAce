这是工程源码入口。首次从 GitHub 拉取后，需要用 Godot 运行工程，或先导出网页版本。

参与开发 · 直接运行工程

  1. 使用 Godot 4.7.2 导入本文件夹中的 project.godot。
  2. 等待资源导入完成，按 F5 运行，点击“单机游玩”即可测试。

模型和游戏源码已包含在仓库中；单机调试无需服务器、Node.js 或 Blender。

需要浏览器版本

按照 协作开发指南 配置 Godot、Node.js 和网页导出模板，再运行文件夹中的 重新导出网页版.cmd。完成后重新打开本页即可进入游戏。

导出结果位于 build/web/；分享试玩时请发送完整的 dist/BadmintonAce-Web.zip，不能只发送 HTML。源码包不包含这些生成文件。
